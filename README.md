# AnnaKam — Музыка

Публичная статическая сборка музыкального сайта AnnaKam для GitHub Pages. В каталоге размещены две композиции, включённые в релиз v002: «Пульс Вакума (Vocal)» и «Chrono Loop Anomaly».

Адрес сайта: https://wadim0041.github.io/annakam-music-site/

Публикация настроена из ветки `main`, корень (`/`). Исходная закрытая история проекта и редакционные материалы в этот репозиторий не входят.

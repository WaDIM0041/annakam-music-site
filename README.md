# makanna Music Studio

Музыкальный сайт makanna: 16 локальных MP3, клип «Зимний вечер», отдельные внешние плееры Suno и радио VK.

Действующий сайт: https://wadim0041.github.io/annakam-music-site/
Рабочая ветка: `main`. Правила нумерации и фирменного знака — в `AGENTS.md`.

Для локального просмотра запустите из папки проекта `python -m http.server 5094`, затем откройте http://127.0.0.1:5094/. Это тестовый сервер, не использовать для хостинга.

Подготовка переноса и ограничения: `HOSTING_HANDOFF.md`. Общие лайки и счётчик прослушиваний пока не реализованы; для них потребуется серверная часть и хранилище.
